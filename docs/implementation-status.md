# 구현 상태 — v0.4 / 2026-10-04

로컬 GUI와 stdio MCP 19개 도구에서 동일한 프로젝트·레시피·소재·생성 작업을 사용한다. 두 레퍼런스의 전체 모드와 설정을 조사해 기능 대응을 확장했다. [전체 대조와 113개 컨트롤 매핑](reference-audit.md)을 구현 범위의 기준으로 삼는다.

- 이중 외곽선, 3색 그라데이션, 그림자/발광, 메인·서브 독립 스타일, 가로/세로/다중 열, 9개 앵커, 자동 축소와 줄바꿈.
- 장식 9종 + 없음: 타이틀 틀/박스/코너/띠/테이프/위아래 선/밑줄/사이드 선/바. 시계 방향 테두리, 둥근 박스, 띠 페이드, 움직이고 점멸하는 테이프.

- 이미지 원본 보존과 정규화, 눈·불꽃·색종이, 연속/일괄 방출과 시드.

## 구조와 실행

`core`가 검증과 명령을, `local-service`가 저장·빌드·브라우저 검증을 소유한다. `shared/options`와 `shared/sequence`는 선택 항목과 절대 시간표를 제공한다. 렌더러는 이 상태를 소비한다. Flutter는 Dart 대응 구현을 공통 수치 fixture와 비교한다. Phaser/Three는 런타임 CanvasTexture, Flutter는 CustomPainter를 사용한다.

생성물은 GameTool 서비스·MCP·API 키·CDN에 의존하지 않는다. 단, 사용자가 설치 폰트 이름을 지정하면 대상 기기에 해당 폰트가 필요하다. 다른 기기에 전달할 폰트는 파일 등록으로 포함한다. 원본 이미지·폰트와 기존 프로젝트는 덮어쓰지 않는다.

## 검증

- 레퍼런스 구현 단계의 `npm test`: 25개 계약 테스트(현재 재사용·파티클 확장 포함 34개). 90개 프리셋의 스키마, 페이지·반복·서브·방향, 88개 폰트 파일과 라이선스/hash, TTF/WOFF/WOFF2 변환 및 원본 보존 포함. 실제 Adobe Source Sans 3 OTF의 판독과 원본 보존도 별도 확인했다.
- `npm run build`: TypeScript 검사와 편집기 빌드.
- 레퍼런스 구현 단계의 `npm run reference:visual`: 실제 Phaser/Three 컴포넌트로 각각 148개 구성 렌더(현재 스크립트에는 새 파티클 10종도 포함; 새 파티클 검증은 위 별도 보고서 참조). 두 엔진 각각 16개 역방향 seek 픽셀 검증. 빈 결과·외부 요청·런타임 오류 검사.
- `npm run smoke`: 실제 MCP를 통해 이미지와 사용자 폰트를 가져와 3개 대상을 생성·분석·빌드·실행. Flutter 생성 테스트 341개에는 80개 구성의 여러 시점과 painter 실행이 포함된다.
- 편집기: 65/8/7 프리셋 분류와 검색, OTF 업로드, 페이지 간격·커서·폰트 저장 및 재접속 복원, 390px 화면 폭 검증. 실제 엔진·폰트 준비 후 미리보기를 공개하고 완성 시점에서 시작하도록 확인했다.
- standalone 단계: GameTool 서비스를 종료하고 정적 호스트에서 생성물 실행, 외부 요청 차단, 테두리 초기/중간/완성/퇴장/역방향 캡처 및 선 길이 검사.

최신 성공 증거는 `output/validation/report.json`, `output/validation/reference-gallery/report.json`, `output/validation/editor-check.json`을 기준으로 한다. 과거 실패 작업 폴더를 최신 검증으로 사용하지 않는다.

## 범위 경계

APNG/WebP/PNG 인코딩 옵션은 사용자 지정에 따라 런타임 코드·소스 ZIP으로 대체했다. 원본 사이트의 픽셀 단위 복제품을 의미하지 않는다. 검증 플랫폼은 macOS Chrome 및 Flutter Web이며 native 실기기·서명·배포는 수행하지 않았다. 의존성과 SDK 준비 후 로컬 실행을 확인한 것으로, 깨끗한 OS에서의 오프라인 최초 설치를 뜻하지 않는다.

레퍼런스 밖인 자유 다중 레이어 편집, 셰이더 그래프, 3D 메시 텍스트, WebGPU, 코드 역수입, 설치형 배포 패키징은 현재 제공하지 않는다.
