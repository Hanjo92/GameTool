# 레퍼런스 전체 대조 — 2026-10-04

[문자 이미지 APNG 메이커 v1.07](https://kumachansteps.github.io/trpg-web-tools/tools/text-apng-maker/)와 [배경 모션 메이커 v1.09](https://kumachansteps.github.io/trpg-web-tools/tools/haikei-motion-maker/)의 전체 모드·설정 패널·프리셋을 확인했다. 이전의 전투 개시 한 예시 중심 구현에서 누락됐던 기능을 v0.3에 추가했다.

## 확인 범위와 증거

- 텍스트: 메시지 65개, 트레일러 8개, 장소·시간 7개를 실제 브라우저에서 모두 선택하고 캡처했다. 3개 모드의 텍스트·폰트·움직임·장식·배경/배치 패널도 확인했다.
- 배경: 24개 모션을 각각 재생해 초기/후반 화면을 캡처했다. 27개 이미지 가공 옵션도 같은 입력 이미지로 확인했다. 이미지 순서와 페이드 방향, 단일 이미지의 원본→가공 전환을 별도로 대조했다.
- 공개된 controls/presets/engine 코드는 옵션 이름·단위·타이밍과 화면 관찰을 교차 확인하는 데 사용했다. 원본 렌더러를 제품에 포함하지 않는다. 관찰한 템플릿 설정 값은 GameTool 스키마로 변환했고 예시 문장은 별도로 작성했다.
- 원본 관찰 자료: `output/reference/full-audit/`의 `all-panels.txt`, `preset-visual-index.txt`, `background-visual-index.txt`, `preset-0..79.png`, `background-*-early/late.png`, `filter-0..26.png`.

## 코드 출력으로 바꾼 항목

사용자가 이미지 파일 대신 실행 코드를 지정했으므로 APNG/WebP/PNG 인코딩·팔레트 양자화·파일 용량 목표·프레임 ZIP·투명 여백 자르기는 게임 효과의 기능으로 옮기지 않는다. 이 항목들은 소스 ZIP, 대상 SDK 빌드, 런타임 시간/속도/반복, 논리 해상도와 뷰포트 클리핑으로 대체한다. 24/30/60FPS 이미지 인코딩 대신 호스트의 프레임 주기와 독립적인 절대 초 단위 계산을 사용한다. 사이트의 언어/테마/공유/도움말 링크는 효과 제작 범위에 포함하지 않는다.

## 검증과 한계

`npm test`는 프리셋·타임라인·페이지·방향·반복·폰트 원본/변환/해시를 확인한다. Flutter 생성 테스트는 80개 구성의 여러 시점과 실제 CustomPainter 실행을 포함한다. `npm run reference:visual`은 148개 구성(80개 텍스트, 29개 배경, 27개 필터, 9개 장식, 3개 입자)을 실제 Phaser/Three 컴포넌트로 렌더링하고 역방향 seek 픽셀 재현, 빈 화면, 외부 요청, 런타임 오류를 검사한다. 각 엔진의 캡처와 보고서는 `output/validation/reference-gallery/`에 남는다.

이는 기능과 설정 의미의 대응이며 원본 엔진의 픽셀 복제품은 아니다. 글꼴 메트릭·글로우·필터의 세부 픽셀은 렌더러에 따라 다르다. 사용자 텍스트와 템플릿 샘플도 동일하지 않다. 설치 폰트 이름만 지정하면 대상 기기에 같은 폰트가 있어야 하며, 이식하려면 파일 등록을 사용한다. 검증된 플랫폼은 macOS Chrome과 Flutter Web이다.
