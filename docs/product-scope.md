## 레퍼런스에서 가져올 동작

2026-10-04 공개 페이지의 기능 안내를 확인했다. 실제 출력 성능·품질·내부 구현은 검증하지 않았다. 소스·디자인·이미지의 복제 계획은 없다.

| 참고 | 관찰한 기능 | 코드 제작에 적용 |
| --- | --- | --- |
| [문자 이미지 APNG 메이커](https://kumachansteps.github.io/trpg-web-tools/tools/text-apng-maker/) | 텍스트·폰트·장식·배치, 등장/표시/퇴장, APNG·PNG 출력 | 실행 중 문구·색·시간을 바꿀 수 있는 컷인·타이틀·알림 컴포넌트 |
| [배경 모션 메이커](https://kumachansteps.github.io/trpg-web-tools/tools/haikei-motion-maker/) | 흔들림·팬·줌·페이드·전환, 분위기 가공, WebP 출력 | 게임의 이미지·텍스처에 모션을 적용하는 재사용 컴포넌트 |

PNG/APNG/WebP·스프라이트 시트 내보내기는 초기 MVP에서 제외한다. 미리보기 캡처는 검증 보조 수단이다. 배경 이미지와 폰트 입력은 유지하고, 효과의 움직임은 런타임 코드가 계산한다.

## 대상별 산출물 제안

| 대상 | 기본 산출물 | 통합 경계 |
| --- | --- | --- |
| Flutter | Dart 위젯·컨트롤러·사용 예제 | 일반 Flutter 위젯 트리에 배치; Flame 의존성은 초기 범위 밖 |
| Phaser | TypeScript 컴포넌트·Scene 사용 예제 | 호출자가 제공한 Scene과 이미지 texture key 사용 |
| Three.js | TypeScript 효과 객체·사용 예제 | 호출자가 제공한 scene/group·렌더 루프에 연결; 기본은 2D HUD/평면 연출 |

각 출력에는 effect 설정, 필요한 보조 소스, 의존성·소재 목록, 통합 안내, 검증 결과가 포함된다. 외부 이미지·폰트가 필요한 경우 누락된 파일과 등록 방법을 명시한다. 생성된 파일을 사용자 프로젝트에 자동 덮어쓰지 않는다.

세 대상은 모두 제품 지원 범위다. 정확한 SDK 버전과 실제 검증 플랫폼은 구현 시 확정한다. 한 대상의 성공으로 나머지를 지원 완료로 표시하지 않는다.

## 첫 MVP 후보

| 기능 | 공통 첫 범위 | 후속 확장 |
| --- | --- | --- |
| 텍스트 | 여러 줄, 크기·색·정렬, 페이드·슬라이드·확대, 등장/유지/퇴장 | 외곽선·그림자, 글자별 타이핑·웨이브·글리치 |
| 배경 | 단일 입력 이미지, 줌·팬·흔들림·페이드, 모션 강도·seed | 복수 이미지 전환, 물결, 색감·셰이더 효과 |
| 편집 | 프리셋, 논리 화면 크기, 대상 선택, 재생/정지·시간 이동, 저장/열기 | 레이어 합성, 실행 취소/다시 실행 |
| 생성 코드 | 텍스트·스타일 매개변수, 재생/정지/시점 이동/반복·종료·자원 해제 | 복합 타임라인·이벤트, 고급 엔진 전용 기능 |
| 에이전트 | 지원 범위 조회, 레시피 수정, 대상별 미리보기, 코드 생성·검증 | 배치 변형 생성, 프리셋 라이브러리 |

기본 동작의 공통 부분을 먼저 구현한다. 셰이더·필터·텍스트 레이아웃은 엔진별 차이가 있으므로 기능별 지원표를 둔다. 미지원 기능은 생성 전에 알리고 조용히 생략하지 않는다.

## 사용자 화면 초안

- 왼쪽: 텍스트/배경 도구, 프리셋, 입력 소재.
- 가운데: 선택한 대상 환경의 미리보기, 재생·시간 이동.
- 오른쪽: 텍스트·스타일·모션·레이아웃 속성.
- 아래: 등장/유지/퇴장 타임라인과 대상별 지원 상태.
- 코드 탭: 대상·컴포넌트 이름, 생성 소스, 사용 예제, 소재·의존성, 검증 결과.

편집기에는 미리보기 모드와 실제 실행 환경을 표시한다. 빠른 공통 미리보기를 추가하더라도 대상 엔진 검증과 구분한다.

## 남은 제품 결정

설치형 앱 패키징 여부, SDK별 지원 버전, Flutter의 우선 검증 플랫폼은 미정이다. Three.js의 월드 공간 3D 효과, UI 패널·버튼·배지, 파티클·충격파는 확장 후보로 둔다. 기존 5개 문서의 이미지 내보내기 우선 계획은 이 코드 생성 계획으로 대체한다.
