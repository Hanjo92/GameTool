# 개발 순서와 검증

> 이 문서는 목표 설계입니다. 현재 구현과 차이는 [구현 상태](implementation-status.md), 현재 도구 입력은 [MCP 계약](mcp-contract.md)을 기준으로 확인하세요.
첫 텍스트 구현을 진행했으며 실제 완료·검증 상태는 구현 상태 문서에 기록한다. 사용자 지정 지원 범위는 Flutter·Phaser·Three.js이며, 아래 모든 단계에서 대상별 상태를 기록한다.

## 1단계: 공통 레시피와 세 대상의 최소 코드 생성

산출물:

- 텍스트 페이드 한 가지를 표현하는 공통 스키마·시간 평가 규약·지원 프로파일.
- Flutter Dart 위젯, Phaser TS 컴포넌트, Three.js TS 객체를 생성하는 최소 생성기.
- 생성물에 필요한 보조 소스·소재 안내·사용 예제·manifest.
- GUI·MCP에서 레시피를 생성/수정/저장하고 동일 생성 명령을 호출하는 최소 흐름.

완료 기준:

- 같은 입력·버전에서 같은 소스 생성. 각 언어의 따옴표·줄바꿈·역슬래시·보간 구문을 안전하게 처리.
- 세 대상의 생성물을 실제 예제 앱에 가져와 실행. 생성기 템플릿 문자열만 검사하고 완료하지 않음.
- Flutter: 생성 예제의 analyze, widget test, 선택 플랫폼 build 및 실행 확인.
- Phaser·Three.js: 생성 예제의 TypeScript 검사·build·브라우저 실행·콘솔 오류 확인.
- 처음/중간/끝의 opacity와 시간 이동 동작을 공통 fixture와 비교.
- 생성된 예제를 GameTool 서비스 종료 후 실행해 런타임 독립성 확인.
- GUI/MCP 변경 충돌 검사, 실제 MCP subprocess 생성 흐름 확인.

우선 위험: SDK 버전 고정, Dart/TS 타임라인 동등성, Three.js HUD 좌표, Flutter 미리보기 빌드 시간. 하나라도 toolchain 부재로 확인하지 못하면 해당 대상은 미검증으로 남긴다.

## 2단계: 텍스트·배경 코드 제작 MVP

산출물:

- 텍스트의 슬라이드·확대, 등장/유지/퇴장과 런타임 문구·색 변경.
- 이미지 입력과 줌·팬·흔들림·페이드.
- 대상별 실제 생성 코드를 실행하는 미리보기, 타임라인 이동, 코드 보기.
- 재생/정지/restart/seek/반복/속도 제어, 자원 해제.
- 코드 생성·검증 작업의 진행률·취소·구조화 오류.

완료 기준:

- 경계 시점·0초 구간·반복·ping-pong·일시정지·속도 변경·역방향 seek를 공통 fixture로 검증.
- 한글·영문·명시적 줄바꿈·폰트 준비·투명도·클리핑·화면 크기 변경을 실제 화면에서 확인.
- 30/60/120Hz 구동에서도 같은 논리 시점의 변환 결과 일치. 엔진 간 글꼴 픽셀 일치를 완료 조건으로 삼지 않음.
- 입력 이미지 크기·종횡비에 따른 cover/contain 동작 확인.
- Flutter dispose, Phaser Scene 재시작, Three.js 객체 제거/재생성 시 리스너·자체 GPU 자원 누수 검사. 빌려 받은 자원은 보존.
- 생성 도중 편집해도 고정 revision의 결과 유지. 결과 hash와 검증 이력 연결.
- 미지원 기능·누락 SDK·손상 소재·경로 탈출·쓰기 실패·취소에서 명확한 실패 상태와 기존 파일 보존.

## 3단계: 로컬 배포·통합 안정화

산출물:

- 최초 실행, SDK 사전 점검, 작업 디렉터리 선택, 서비스 재시작·잠금 복구.
- 세 환경에서 검증된 최소 통합 예제와 SDK 호환 표.
- 생성 파일/사용자 통합 파일의 경계와 재생성 안내.
- 라이선스·버전 기록, 실제 동작하는 실행 명령과 MCP 연결 예시.
- 네트워크를 차단한 상태의 편집·생성·미리보기·생성물 실행 검증.
- 선택한 형태의 로컬 배포물; 데스크톱 설치형은 별도 패키징.

완료 기준:

- 준비된 SDK·의존성만으로 오프라인 핵심 흐름 성공. 최초 설치의 네트워크 요구는 별도로 기록.
- 실제 생성 패키지를 별도 예제 프로젝트에 통합하고 문구·모션 값을 변경해 실행.
- Flutter Web 결과와 macOS/iOS/Android 등의 플랫폼 증거를 구분하고 검증한 플랫폼만 표기.
- Phaser·Three.js의 검증 버전·렌더러·브라우저를 기록. 무제한 버전 호환을 주장하지 않음.
- 클라이언트 설정 변경·서명·외부 배포는 해당 작업 지시 범위에서 수행.

이후 UI 패널·버튼·배지, 파티클·충격파, 셰이더와 고급 배경 전환을 대상별 capability로 확장한다.
